1. Have you used Git before? If so, in what context?
Yes. I first used Git for one of my classes where we learned the basics of version control—cloning repositories, staging and committing changes, branching, and pushing to GitHub. It was for database code file, where we had to write SQL queries and manage numerious versions of out scripts. 

2. Which Git client (if any) did you choose? Why?
I use Git through Visual Studio Code. The built-in Source Control panel makes common tasks straightforward (staging/unstaging, commit messages, reviewing diffs). It is simply just the most convenient for when working with git.

3. What was the most interesting thing you learned about Git today?
How clearly Git can separate the working directory, the staging area, and the commit history along with how that enables focused commits. I also learned how branching keeps main stable while I make changes, and how merge tools in VS Code help resolve conflicts without losing any work.
