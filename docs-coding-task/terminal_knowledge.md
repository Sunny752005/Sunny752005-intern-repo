Which terminal client did you choose? Why?
I chose the default macOS terminal because of the convenience, since it is already downloaded on my macbook and is easy to use. It also uses zsh, which is the default shell for apple  and has modern features like autocompletion and better scripting support compared to the older bash shell.

What customizations (if any) did you make?
I have not made any major customizations yet, I am only using the basic and default macOS terminal. However, I did enable the dark mode theme in the terminal settings to reduce eye strain during long coding sessions.
