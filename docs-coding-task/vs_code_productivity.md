1. Navigation

Quick Open file: "command+P" / "control+P"

Command Palette: "command+shift+P" / "control+shift+P"

Go to Definition: "F12"

2. Editing

Multiple cursors – add next match: "command+D" / "control+D"

Multiple cursors – select all matches: "command+shift+L" / "control+shift+L"

Toggle line comment: "command+/" / "control+/"

Format document: "command+option+shift+F" / "control+alt+shift+F"

3. Debugging

Start/Continue debugging: "F5"

Toggle Breakpoint: "F9"

Terminal

Toggle Integrated Terminal: "control+"(Mac) /"control+" (Windows/Linux)


/////////Reflection/////////
1. Which shortcuts will be the most useful in your daily work?
The most useful shortcut for me is "command+D" / "control+D" because it allows me to add more than one cursor and edit repeated text together. I also find "command+P" / "control+P" very helpful since it allows me to quickly open files without having to go through folders.

2. How can keyboard shortcuts improve your productivity?
Keyboard shortcuts can improve productivity a lot because they save time and keep me focused on coding. Instead of breaking concentration to use the mouse, I can do common tasks instantly, which makes the workflow faster.
