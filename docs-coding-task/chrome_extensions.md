1. Which extensions did you install? Why?
I installed React Developer Tools to inspect component trees, props, and hooks in the browser and it also adds a Components and Profiler tab to DevTools which can make debugging the React state/props much faster. 

I installed a JSON Viewer so that I can open API responses and they are already formatted with collapsible nodes.

I added Lighthouse to audit performance, accessibility, SEO, and PWA checks directly in the browser with  suggestions that I can act upon.


2. What was the most useful thing I learned?

The most useful thing I learned was how to use Redux DevTools to inspect the Redux state changes over time. Witht he redux devtools extension, I can see the entire state tree, inspect individual actions, and even time travel to previous states. This made it much easier to debug issues related to state management in my React applications.
